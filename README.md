# Propuesta Middleware AMR

Propuesta técnica y comercial de **Patagonia Digital** para **AMR Mutual**: un middleware que unifica los datos de Turismo y Préstamos del sistema de gestión y los distribuye a WoowUp (mail) y Wise CX (WhatsApp).

- `index.html` — propuesta completa (arquitectura, datos por unidad, casos de uso, fases, métricas, inversión y próximos pasos).
- `mockup/index.html` — mockup funcional e interactivo del middleware: recorre el dato por etapas (origen → ingesta → estandarización → perfil unificado → WoowUp → Wise CX → monitoreo), con calculadora de oportunidad editable. Usa **datos de prueba** (100 socios ficticios).

Ambos son HTML estáticos: se abren directo en el navegador. Publicado en Vercel, la propuesta queda en `/` y el mockup en `/mockup`.

Versión: Arquitectura v1.0 · Octubre 2026 · **Confidencial**
