# Propuesta Middleware AMR

Propuesta técnica y comercial de **Patagonia Digital** para **AMR Mutual**: un middleware que unifica los datos de Turismo y Préstamos del ERP y los distribuye a WoowUp (mail) y Wise CX (WhatsApp).

- `index.html` — propuesta completa (arquitectura, datos por unidad, casos de uso, fases, métricas, inversión y próximos pasos). Se abre directo en el navegador.
